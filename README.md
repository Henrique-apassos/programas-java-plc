# Programas Java PLC
Programas em Java utilizados na disciplina de Paradigmas de Linguagens CIn UFPE ministradas pelo professor André Luís de Medeiros Santos.

## Paridigma de programação orientado a objetos
* Foco nos dados (objetos) do sistema, não nas funções
* Estruturação do programa é baseada nos dados, não nas funções
* As funções mudam mais do que os dados
* Objetos e atividades do mundo real

### O que é um Objeto? 
É um agrupamento dos dados e operações que representam um **conseito**
